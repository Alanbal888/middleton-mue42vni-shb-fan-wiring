# Middleton MUE42VNI-SHB Ceiling Fan — Wiring Documentation

## Overview

This repository contains community-documented wiring information for the **Middleton MUE42VNI-SHB ceiling fan**, sold through The Home Depot Mexico.

The documentation covers the internal electrical connections between the fan motor, reversing (direction) switch, pull-chain speed controller, and capacitor.

The purpose of this repository is to help other owners identify and understand the wiring configuration of this particular fan model, especially when repairing or replacing internal components.

## Components Documented

- **Ceiling fan:** Middleton MUE42VNI-SHB
- **Speed controller:** KTE 3089 (E87438), 4-terminal pull-chain switch
- **Capacitor:** CBB6-1, three-section capacitor (3 µF + 4.5 µF + 4.5 µF)
- **Direction switch:** 6-terminal reversing switch

## Background

This documentation was created while troubleshooting a ceiling fan whose motor produced a buzzing sound but failed to rotate.

During the investigation, two potential issues were identified:

1. A disconnected wire on terminal 5 of the reversing switch.
2. Possible incorrect connections after replacing the original pull-chain speed controller.

To better understand the original wiring, the electrical connections were compared against another installed, functioning ceiling fan of the **same model**.

The observations were used to create a wiring summary and an illustrative diagram.
